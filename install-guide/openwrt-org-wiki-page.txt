


====== ZyXEL VMG8825-T50 ======
~~NOTOC~~

/* This template is intended to be used via https://openwrt.org/meta/create_new_device_page . */

The ZyXEL VMG8825-T50 is a cheap but modern modem/router that is provided by ISP's. It supports ADSL, and has an ethernet WAN port. 
The device has built in Wifi 2.4/5Ghz with support up to Wifi AC. It has 4 ethernet port for the LAN network, one USB 2.0 port and one usb 3.0 port.
The firmware on it is fairly restrictive, but not as bad as some other modems. Appears to run some pretty old software.

===== Installation =====

No official/signed install path yet — you need to open the case and use
a serial console. Full walkthrough, exact commands, safety checks:
[[https://github.com/koenieee/VMG8825-T50-Openwrt-support/blob/main/install-guide/README.md|install-guide/README.md]].
This box is only the outline, don't improvise from it alone.

==== Installing OpenWrt ====

  - Open the case, connect a 3.3V serial adapter, confirm the bootloader banner matches the guide's precondition section.
  - Netboot an initramfs kernel over TFTP to get a root shell without touching flash.
  - Back up flash, then build your own patched bootloader from your own bootloader dump — no prebuilt bootloader binary is shipped, see the guide's §5a.
  - Flash [[https://github.com/koenieee/VMG8825-T50-Openwrt-support/blob/main/firmware/vmg8825-t50-era-signed.bin|vmg8825-t50-era-signed.bin]] to the main partition — the factory partition is an automatic fallback, this step is safe to retry.
  - Flash the bootloader you just built — **this one write has no fallback**, back up first.
  - <color red>**Finish by reflashing**</color> [[https://github.com/koenieee/VMG8825-T50-Openwrt-support/blob/main/firmware/vmg8825-t50-era-signed-locked.bin|vmg8825-t50-era-signed-locked.bin]] so the bootloader partition (mtd1) ends up **read-only** again.

==== Opening the case ====

You only need to remove to Philips screws at the back of the unit.
After that, you will be able to separate the back and front plastic pieces of the device.
The parts are still hold together with clips, if you insert a small plastic part in the gap between the two pieces you should be able to pry it open fairly easily.
